# Fictional demo design and calculations

## Dataset

The public application uses a fully fictional dataset. The student and institution labels, programme, course identifiers, credits, letter grades and resulting indices are illustrative. They are not copied from a personal academic document and do not claim institutional affiliation.

The five demo courses are Programming Fundamentals (4 credits, AB), Applied Computing Mathematics (4 credits, BB), Digital Logic (3 credits, BC), Technical Communication (2 credits, AA) and Computing Workshop (3 credits, BB).

## Arithmetic

The illustrative 10-point mapping yields:

(4×9 + 4×8 + 3×7 + 2×10 + 3×8) / 16 = 133/16 = 8.3125.

SPI is displayed as 8.31. The example CPI also displays 8.31 because the fictional dataset contains one semester. No marks, percentage, degree progress or honours eligibility is inferred.

## Interaction model

Dashboard and Results display the fixed fictional example. Calculator and History contain editable planning scenarios, stored on the current browser. Scenario edits do not mutate the fixed demo. Exports distinguish fictional records from planning scenarios.

## Privacy

Only the synthetic dataset is distributed. Private academic documents, actual educational results, birth dates, personal identifiers and verification artifacts are excluded. Source comments, tests, documentation, CSV labels and browser defaults also use fictional examples.

The public demo uses a new browser storage namespace so earlier personal/local datasets are not loaded as its defaults. Existing old browser data is not deleted or published.
